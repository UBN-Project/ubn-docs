Check if the API gateway is online. **No authentication required** -- just hit Send.

### Response

Returns `Healthy` as plain text with a `200 OK` status.

```
Healthy
```

<Tip>
  Use this endpoint for uptime monitoring and as a preflight check before making authenticated API calls.
</Tip>
